# AeroStem
AeroStem is a plant care monitoring device which works in partnership with its companion app. The companion app was made with MIT App Inventor. At the top, it shows the light intensity and soil moisture of the plant. It also allows the user to select which plant specie the plant is, and the app will adjust the recommended values and the notifications based on the selection. The app connects to AeroStem via Bluetooth by the DSD HM-10 Bluetooth module.
